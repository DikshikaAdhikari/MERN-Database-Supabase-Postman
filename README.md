
# Backend CRUD API

A RESTful backend API built with **Node.js**, **Express.js**, **Sequelize**, and **PostgreSQL (Supabase)**. The project implements CRUD operations for **Users** and **Posts**, along with validation, error handling, and database integration.

## 🚀 Features

* User CRUD Operations
* Post CRUD Operations
* User–Post Relationship
* Email & Age Validation
* Error Handling
* PostgreSQL (Supabase) Integration
* API Testing with Postman

## 🛠️ Tech Stack

* Node.js
* Express.js
* Sequelize ORM
* PostgreSQL (Supabase)
* JavaScript (ES Modules)
